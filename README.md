# Clean Me for Windows

Clean up and speed up your PC — beautifully.

**[⬇ Download the latest version](https://github.com/genxnayem-svg/clean-me-windows/releases/latest)** — get `CleanMe-Setup-x.x.exe` under *Assets*, open it, and follow the steps. No admin password needed.

## What it does

- **Optimize** — one click clears junk and frees memory
- **Smart Clean** — browser, app and Windows caches, temp files, Recycle Bin, Windows Update leftovers
- **Disk Map** — a colourful map of what's taking space
- **Large & Old** and **Duplicates** — find forgotten big files and copies
- **Uninstaller** — remove desktop programs and Microsoft Store apps
- **Startup Items** — switch off apps, services and tasks that slow down start-up
- **Memory**, **Disk Health** and **Speed Test**
- Day / Night themes and 10 colour themes
- Updates install inside the app

Everything happens on your PC. Nothing is uploaded.

Windows 10 or 11 (64-bit). If Windows SmartScreen says "Windows protected your PC", click **More info → Run anyway**.
